# 第一人称对话场景

网站直接加载 `assets-v3` 中的面试办公室、办公会议室、学校走廊三个 GLB。各模型包含一个对话对象、四组动作、嘴型与眨眼形变，以及固定第一人称镜头。

同目录的 `.blend` 为可编辑工程，保留家具、场景与人物骨骼。第三版细化了肩袖、领口、袖口、发丝、植物、座椅、门窗五金和走廊公告。

运行根目录 `node server.cjs` 后，三维窗口在聊天预演页中加载。也可在本目录运行 `node server.cjs`，打开 http://127.0.0.1:4174 查看独立场景。

`vendor` 保留 Three.js 和基础人体网格的许可说明。人物頭部基础网格使用 MakeHuman CC0 资源，环境、服装和道具由项目程序构建。外观为固定预设，尚无语音及音素口型同步。
